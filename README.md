# CLA signatures

This branch holds only the log of RiftEye Contributor License Agreement signatures, `signatures/cla-v1.json`. The CLA workflow (`.github/workflows/cla.yml` on `main`) appends to it when a contributor comments the signing sentence on a pull request.

- Do not protect this branch: the workflow must be able to push to it.
- Do not edit the log by hand, except to correct an error, and then record why in the commit message.
- A new CLA version gets a new file (`cla-v2.json`); old logs are never rewritten.

See [CLA.md](https://github.com/effe-exe/RiftEye/blob/main/CLA.md).
