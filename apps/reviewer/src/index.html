Wardeye reviewer

Open a review pack to start.

A pack holds the model's guesses. You say whether each one is right. Nothing leaves this page: answers are saved in this browser until you export them.

Not in the list (some tokens)? Pick “Use …” to keep the name you typed. Enter on an empty box: wrong, and you don't know what it is. Esc: go back.

    All done

    Press Export and send the file back. You can still go back with ← or Z to change an answer.

    Keyboard shortcuts

    Ythe guess is correct
    1–9wrong: it is that numbered option
    Nwrong: type what it is and press Enter (Enter alone if you don't know)
    Scan't tell (blurry, covered, not a card)
    Zundo the last answer
    ← →previous / next item

    Say S rather than guess: a wrong label does more harm than a missing one.
